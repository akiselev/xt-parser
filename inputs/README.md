# Private inputs

This directory is ignored except for this file. Put local-only source material
here, for example:

- `reference/xt-reference.md`;
- versioned `sch_*` schema distributions;
- controlled XT fixtures whose redistribution status is unknown; and
- oracle outputs containing proprietary model data.

Every input used by a checked-in claim must have its SHA-256 and provenance in
`evidence/manifest.toml`. Do not rely on filenames alone.
